# Trecento Network v0.6.4 — remove activity washes

The gray activity/influence bubble overlays have been removed from the graph.

This is a presentation change only:
- no gray regional/activity ellipses are rendered
- the legend no longer describes activity washes
- artist activity data are left in the underlying records for possible future use
- explicit graph relationships remain the visual mechanism for influence/workshop/family connections

All v0.6.3 selection-centering behavior is retained.
